# Portofolio Kedai Kopi Senja

Website statis (HTML, CSS, JavaScript) tanpa proses build.

## Halaman
index.html (Home), profil.html, project.html (filter kategori), kontak.html (formulir, pengiriman SIMULASI).

## Menjalankan
Opsi 1: buka `index.html` langsung di browser.
Opsi 2 (disarankan), di folder ini jalankan salah satu:
- `python -m http.server 5500` lalu buka http://localhost:5500
- `npx serve .`
- VS Code: ekstensi Live Server -> Open with Live Server

## Yang masih perlu diganti
Seluruh teks bertanda "(contoh)": alamat, email, jam buka, nama tim, tahun, dan daftar project. Foto saat ini berupa ilustrasi SVG di `assets/img`; ganti dengan foto asli bila ada.
Formulir kontak belum punya backend.
